## Defect Summary
The home page used a hardcoded welcome message and an unnecessary success paragraph. The requirement is to show `Welcome guest` when the user is not signed in, or `Welcome <displayName/email>` when a user is logged in, without the extra confirmation text.

## Root Cause Analysis
The page template in [src/app/home/home.ts](src/app/home/home.ts) was hardcoded to `Welcome!` and included the static copy `You have successfully logged in.`. There was no logic to read the authenticated user from `AuthService`.

| File | Location | Before (Defective) | After (Fixed) | Reason |
|---|---|---|---|---|
| src/app/home/home.ts | Home.welcomeMessage | Hardcoded heading and success paragraph | Computed greeting from `AuthService.user()` | Ensures guest and signed-in user names render correctly |
| src/app/home/home.ts | template | `You have successfully logged in.` | Removed | Matches the issue requirement and removes redundant copy |
